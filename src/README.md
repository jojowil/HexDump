# HexDump

This project is for my students studying system internals. We decided to take some time to examine how certain systems store data and using the hexdump facility was hugely helpful.

While we could have just used tools like ```od``` it was a good opportunity to discuss how these tools work. So, we built some.

## Concept

Take a general algorithm and write it for multiple languages.

## Implementation

This is done in Java, C, and Python, so far, to demonstrate languages to my students.

Everything in this design is Java 25, C23, and Python 3.11 compatible.
